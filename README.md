# TradeVerse

Markets as a daily skill game. A habit-forming, regulation-safe, skill-first product built on top of live NSE/BSE data.

> Not a trading app. No real money. No KYC. No demat.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Build

```bash
npm run build
npm run start
```

## Deploy

Deploy-ready for Vercel. Connect the repo in the Vercel dashboard; no extra config needed.

## Phased build

- Phase 1 — Marketing site (landing, hero offerings, personas, CTA)
- Phase 2 — Auth & profile (age-gated signup, profile)
- Phase 3 — Daily Chart Challenge (H1)
- Phase 4 — Friend Leagues (H2)
- Phase 5 — Data layer (mock, then live NSE/BSE)
- Phase 6 — Polish (analytics, SEO, perf)
